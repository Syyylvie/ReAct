This repository is a replication of the paper ReAct: SYNERGIZING REASONING AND ACTING IN LANGUAGE MODELS.\\


--tools.py build Action Space in the paper\\
--recommend.py recommend similar entities based on word2vec models\\
--model.py similarity computation and NER recognition\\
--agent.py invocation using deepseek-r1 and langchain interface\\
--word_vecs_glove saved word vectors, loaded when recommending entities\\
