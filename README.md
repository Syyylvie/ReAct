This repository is a replication of the paper ReAct: SYNERGIZING REASONING AND ACTING IN LANGUAGE MODELS.\n
--tools.py build Action Space in the paper\n
--recommend.py recommend similar entities based on word2vec models\n
--model.py similarity computation and NER recognition\n
--agent.py invocation using deepseek-r1 and langchain interface\n
--word_vecs_glove saved word vectors, loaded when recommending entities\n
